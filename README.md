# code skip VDO

สคริปต์ Tampermonkey สำหรับเว็บ `elearning.set.or.th` ที่จะ:

- เลื่อนวิดีโอไปจนจบ (ถ้าเว็บไม่ให้กรอ จะเล่นที่ความเร็ว 16 เท่าแทน)
- กดปุ่ม "ถัดไป" และกดยืนยันในป๊อปอัป "ต้องการเรียนบทถัดไป" ให้เอง
- ทำซ้ำไปเรื่อยๆ และหยุดเองเมื่อถึงหน้าแบบสำรวจ

ไฟล์สคริปต์: [`auto-skip-to-survey.user.js`](auto-skip-to-survey.user.js)

---

## วิธีติดตั้งบนเครื่องใหม่ (Google Chrome)

### 1. ติดตั้ง Tampermonkey

เปิด Chrome Web Store แล้วค้นหา **Tampermonkey** จากนั้นกด **Add to Chrome / เพิ่มใน Chrome**

### 2. อนุญาตให้ Tampermonkey รันสคริปต์ (สำคัญ ข้ามไม่ได้)

1. พิมพ์ `chrome://extensions` ในแถบที่อยู่ แล้วกด Enter
2. เปิด **Developer mode / โหมดนักพัฒนาซอฟต์แวร์** ที่มุมขวาบน
3. กด **Details / รายละเอียด** ของ Tampermonkey
4. เปิดสวิตช์ **Allow User Scripts / อนุญาตสคริปต์ผู้ใช้**

ถ้ายังไม่ได้เปิดข้อนี้ เวลากดไอคอน Tampermonkey จะมีแถบสีฟ้าเตือนว่า "Please enable the Allow User Scripts" และสคริปต์จะไม่ทำงาน

### 3. เพิ่มสคริปต์

1. เปิดไฟล์ [`auto-skip-to-survey.user.js`](auto-skip-to-survey.user.js) บน GitHub แล้วกดปุ่ม **Copy raw file** (ไอคอนรูปสี่เหลี่ยมซ้อนกันที่มุมขวาบนของโค้ด)
2. กดไอคอน Tampermonkey บน Chrome แล้วเลือก **Create a new script...**
3. กด **Ctrl + A** เพื่อเลือกโค้ดตัวอย่างที่มีอยู่ทั้งหมด แล้วกด **Ctrl + V** วางโค้ดทับลงไป
4. กด **Ctrl + S** เพื่อบันทึก

> ต้องวางโค้ดครบทั้งไฟล์ ทั้งส่วนหัว `// ==UserScript==` และโค้ดด้านล่าง ถ้าวางแค่ส่วนหัว สคริปต์จะไม่ทำอะไรเลย

### 4. ใช้งาน

1. เข้าเว็บ `elearning.set.or.th` แล้วเปิดคลิปแรกของคอร์ส
2. กด **F5** เพื่อรีเฟรช สคริปต์จะเริ่มทำงานเองภายใน 3 วินาที
3. ไม่ต้องวางโค้ดลงใน Console เอง (ถ้าวางด้วย สคริปต์จะรันซ้อนกันสองตัว)

## เช็กว่าสคริปต์ทำงานอยู่หรือไม่

- ไอคอน Tampermonkey จะมีเลขสีแดงขึ้นมา
- กด **F12** แล้วไปที่แท็บ **Console** จะเห็นข้อความแบบนี้ขึ้นเรื่อยๆ

```
🚀 สคริปต์เริ่มทำงานแล้ว
🔄 รอบที่ 1
⏩ ข้ามวิดีโอ (...)
🟢 กดในป๊อปอัป: เรียนบทถัดไป
✅ ถึงแบบสำรวจแล้ว หยุดทำงาน
```

## วิธีหยุด

กดไอคอน Tampermonkey แล้วปิดสวิตช์ของ **Auto skip to survey** จากนั้นรีเฟรชหน้า

เรียนจบแล้วควรปิดสคริปต์ไว้ ไม่งั้นมันจะกดปุ่มให้เองทุกครั้งที่เข้าเว็บนี้

## แก้ปัญหา

| อาการ | วิธีแก้ |
|---|---|
| ไม่มีข้อความ 🚀 ใน Console | ยังไม่ได้เปิด Allow User Scripts (ขั้นที่ 2) หรือยังไม่ได้รีเฟรชหน้า ถ้ายังไม่ได้ ให้ปิด Chrome ทั้งหมดแล้วเปิดใหม่ |
| มี 🚀 แต่ไม่มี 🔄 | วางโค้ดไม่ครบ ให้คัดลอกไฟล์ใหม่ทั้งไฟล์ |
| มี 🔄 แต่ไม่กดปุ่มถัดไป | ปุ่มบนเว็บใช้คำอื่น ให้เพิ่มคำนั้นใน `NEXT_WORDS` หรือ `CONFIRM_WORDS` ในโค้ด |
| วิดีโอดีดเวลากลับที่เดิม | เว็บห้ามกรอ ให้ลบบรรทัด `v.currentTime = ...` ออก สคริปต์จะเล่นที่ความเร็ว 16 เท่าแทน |
| ใช้กับเว็บอื่น | แก้บรรทัด `@match` ในส่วนหัวเป็นโดเมนของเว็บนั้น เช่น `*://เว็บอื่น.com/*` |

> หมายเหตุ: บางเว็บเช็กเวลาดูคลิปที่ฝั่ง server ถึงข้ามคลิปได้ ระบบก็อาจไม่นับว่าเรียนจบ
